# Core Template

Copy to `cores/<your-hdl-name>/` and implement the same RV32I pipelined core with hazard unit as `cores/verilog/`.

This template is intentionally minimal — no HDL sources. Use any language or flow you like; match the **interfaces and memory map** below.

## Tournament contract

### FPGA top (synthesis)

Expose at minimum: `clk`, `btn`, `led1` … `led8`  
Pin constraints: `synth/tec0117.cst` (Trenz Tec0117 / GW1NR-9)

### Simulation (RISCOF)

Your simulator must:

1. Load `./files/text.txt` (instruction words, hex) and `./files/data.txt` (`address word` lines for data RAM)
2. Run until `ecall` with `a0 == 18`, then dump data memory to `DUT-<name>.signature` (same format as the Verilog reference testbench)
3. For interactive smoke tests, handle `ecall` with `a0 == 10` (exit) as in `hello_world.s`

Memory map (must match `make program` output):

| Region | Address | Sim size |
|--------|---------|----------|
| Instruction | `0x00000000` | ≥ 8192 bytes (power-of-two) |
| Data | `0x10000000` | 65540 bytes (`riscof_dmem_size` in `core.yaml`) |
| GPIO / LEDs | `0x20000000` | MMIO byte/word for LED demo |

### Layout

```
cores/<your-hdl-name>/
├── core.yaml       # Framework metadata
├── Makefile        # program + your sim/synth rules
├── programs/       # Shared demo / smoke-test assembly
├── files/          # Generated by `make program`
├── synth/          # Board constraints (optional until FPGA)
└── rtl/            # Your sources (structure is up to you)
```

## Steps

1. `cp -r cores/_template cores/myhdl`
2. Edit `core.yaml` (`name`, `hdl`, `simulator`, `top_module`, …)
3. Add your implementation under `rtl/` (or another layout — update Makefile and RISCOF plugin paths)
4. Implement `make sim` and `make synth` in your Makefile
5. `make -C cores/myhdl PROGRAM=hello_world.s program` — builds memory init files
6. `python3 scripts/generate_riscof_plugins.py --core myhdl` — extend plugin if not using Icarus Verilog
7. `make test CORE=myhdl`

Reference Verilog implementation: `cores/verilog/`.
